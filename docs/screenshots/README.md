# Project screenshots

`grafana-network-overview.png` and `grafana-latency-and-clients.png` are the two user-provided Grafana captures from the main-router trial on 2026-11-25. Together they show DNS traffic, outcome metrics, latency, client summaries, and blocked domains. They include local client addresses and queried-domain telemetry, so the repository is private.

The sanitized Serial Monitor text excerpt is in `../serial-monitor-session.txt`. A Serial Monitor image is not included yet because the desktop capture interface did not save one. Before adding a Serial Monitor screenshot, make sure it does not expose Wi-Fi credentials, OTA passwords, API tokens, private keys, or client/domain logs.
